# رتبه‌یار — پلتفرم هوشمند مشاوره کنکور

- **`docs/masterplan.html`** — نقشه راه کامل (۱۹ بخش): کنکور ایران ۱۴۰۴–۱۴۰۶، بازار و رقبا، الگوهای جهانی،
  پرسوناها، چهار پنل (مدیر / مشاور / دانش‌آموز / والدین)، کلونِ هوش مصنوعی مشاور (RAG + ارزیابی)،

  فایل مستقل است (بدون وابستگی به سرور)؛ حالت روشن/تاریک خودکار + سوئیچ دستی.
